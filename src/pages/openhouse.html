Open House: the sign-in sheet that stays yours.

I built this for my own open houses. Print a QR poster and guests scan it on their own phone, or run it on a tablet that keeps taking sign-ins when the Wi-Fi drops. Every answer lands on a real contact record, so you leave knowing who to call.

  • QR poster for guests' own phones
  • Tablet mode that keeps working offline
  • Every sign-in saved as a real contact record

It is free, there is no card, and there is no signup link. I set up each agent's copy by hand so it is actually working before you rely on it at a real open house.
